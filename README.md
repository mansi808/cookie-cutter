# cookie-cutter <img width="39" height="38" alt="cookie_icon" src="https://github.com/user-attachments/assets/c270b89f-bdf3-4199-b406-43f9c37cb53f" align="center"/>
Browser extension which automatically rejects cookies on websites<br>
Currently only functional on Chrome<br>

-- Uses a dictionary list for detection.<br>
-- CSS selectors from 'i don't care about cookies' and 'consent-o-matic.<br><br>

<h3>Installation</h3>
<h4>Chrome</h4> 
Clone or download the repository.<br>
Navigate to chrome://extensions/, turn on 'Developer Mode' and click 'Load Unpacked' for the cloned folder.
